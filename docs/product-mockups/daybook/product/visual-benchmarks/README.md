# Daybook visual benchmarks

`01-week-book-master-direction.png` is the approved master visual direction for
Daybook. It establishes the classroom-atelier system described in PRD Section
12.1.

The remaining coordinated benchmarks must be added here for:

1. Plans.
2. Classroom.
3. Resources.
4. Reflections.
5. Teaching View.

Each must interpret the approved system for its specialist workspace rather
than repeat the Week Book composition. Current explorations live in
`../visual-concepts/`; Direction A and the rejected first pass are non-normative
process history.

The deployed interactive mockup at
<https://wonderroom-lesson-studio.tim-a-wood.chatgpt.site> and baseline commit
`f916bbe0a23e8ae753d5f18bcea8473151f52dbb` remain normative for structure,
content hierarchy, navigation, workspace relationships, states, and interaction
promises. The PRD remains authoritative for scope, policy, behaviour, and
acceptance.

The `reference-captures/` directory contains lower-fidelity captures of the
interactive mockup. They are structural inputs only and are not visual
benchmarks.

## Approved direction record

- Selection: classroom-atelier Direction B.
- Mode: built-in image generation, new-image workflow.
- Direction: straight-on 16:10 desktop product renders; dark green primary rail;
  warm contextual surfaces; asymmetric editorial grid; woven/index cues;
  connected time and phase paths; bold serif plus humanist sans-serif;
  restrained annotations; feasible early-years materials; strong truthful
  photography; no device frames, generic AI styling, cartoon/game language,
  glassmorphism, or impossible interactions.
- Production use: implementations must reproduce the approved
  quality and design intent with deterministic UI components and approved
  resource imagery rather than embedding renders as application screenshots.
