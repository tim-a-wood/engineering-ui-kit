# Daybook visual-direction explorations

These images preserve design exploration history. The classroom-atelier
Direction B was approved and copied into `../visual-benchmarks/` as the binding
Week Book master direction.

## Current candidates

- `week-book-direction-a-editorial-journal.png` — non-normative alternative: a materially rich open
  teaching journal with clothbound navigation, indexed days, a two-page lesson
  spread, classroom preparation, and strong resource photography.
- `week-book-direction-b-classroom-atelier.png` — approved source exploration: a modern classroom
  atelier with woven lesson tabs, an asymmetric editorial lesson canvas,
  continuous teaching-path navigation, and a photographic preparation rail.

Direction B is binding because it is visually distinct without depending on a
literal book metaphor in every workspace. Direction A remains process history
and must not be treated as a competing target.

## Generation record

- Mode: built-in image generation, new-image workflow.
- Shared prompt direction: create a completely new, straight-on 16:10 desktop
  Daybook interface; preserve the established product content but redesign the
  composition; use an early-years teacher and classroom-derived language;
  combine editorial typography, bottle green, restrained subject colours,
  feasible classroom materials, and strong resource photography; avoid generic
  SaaS cards, prompt/chat patterns, AI motifs, cartoons, device frames,
  glassmorphism, and infeasible interactions.
- Direction A prompt emphasis: high-end independent educational publisher plus
  a materially rich open teaching journal.
- Direction B prompt emphasis: contemporary classroom atelier, planning wall,
  woven index tabs, and modern editorial software without literal book rings or
  a desktop background.

The files under `rejected-first-pass/` are retained only as process history.
They were rejected because they followed the interactive mockup too literally.
