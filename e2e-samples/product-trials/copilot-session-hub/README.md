# Copilot Sessions

Track Copilot sessions, progress, issues, outputs, and next actions across engineering projects.

## Product structure

- Architecture style: event-driven work tracker
- Starting structure: Domain-centered
- Session workspace (experience): Shows active agent work, decisions, issues, and next actions.
- Session ledger (domain): Owns session identity, state, progress, and history.
- Issue queue (workflow): Routes blockers, decisions, and review requests.
- Evidence store (platform): Preserves outputs, links, checks, and completion evidence.

## User tasks

- Start Copilot session
- Update session progress
- Record session issue
- Link branch output
- Record next action
- Review active sessions
- Close completed session
- Reopen paused session

## Protected outcome

- Never delete unresolved session
