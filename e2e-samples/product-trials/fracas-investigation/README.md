# FRACAS Investigations

Capture failures, analyse causes, control corrective actions, and verify closure.

## Product structure

- Architecture style: closed-loop reliability system
- Starting structure: Domain-centered
- Case workspace (experience): Combines failure evidence, analysis, actions, and recurrence.
- Failure ledger (domain): Owns failure reports, classifications, assets, and occurrence data.
- Cause analysis (domain): Owns hypotheses, evidence, causal links, and conclusions.
- Action control (workflow): Owns containment, correction, verification, and overdue work.
- Trend service (platform): Computes Pareto, repeat rate, exposure, and recurrence signals.

## User tasks

- Record failure report
- Classify failure mode
- Record containment action
- Analyze root cause
- Link causal evidence
- Assign corrective action
- Verify action closure
- Monitor failure recurrence

## Protected outcome

- Never delete open corrective action
