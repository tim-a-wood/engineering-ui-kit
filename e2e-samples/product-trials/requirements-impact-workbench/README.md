# Requirements Change-Impact Workbench

Trace requirement changes through design, interfaces, implementation, verification, and approval.

## Product structure

- Architecture style: graph-analysis decision system
- Starting structure: Domain-centered
- Impact workspace (experience): Shows change scope, trace paths, decisions, and review state.
- Trace index (platform): Indexes requirements, design, code, tests, and approved revisions.
- Impact engine (domain): Traverses dependencies and classifies affected records.
- Decision control (workflow): Owns dispositions, review assignments, and approval.

## User tasks

- Import requirement change
- Trace affected design
- Compare trace revision
- Review module impact
- Assign rework action
- Estimate change effort
- Approve impact decision

## Protected outcome

- Never delete unreviewed impact
