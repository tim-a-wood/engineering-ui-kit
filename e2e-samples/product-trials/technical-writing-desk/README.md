# Technical Writing

Draft technical content, enforce ASD-STE100, manage comments, and approve controlled documents.

## Product structure

- Architecture style: document-centered authoring system
- Starting structure: Experience-first
- Document control (workflow): Coordinates drafts, revisions, reviews, and controlled export.
- STE checker (domain): Applies approved terminology and ASD-STE100 writing rules.
- Comment service (domain): Owns review threads, decisions, and resolution state.

## User tasks

- Draft technical note
- Check STE wording
- Compare document revision
- Record review comment
- Approve controlled revision
- Export approved document

## Protected outcome

- Never use prohibited term
